## 🛠️ كيفية تشغيل الموقع محلياً على جهازك

الموقع مبني بـ HTML/CSS/JS صافي، مما يجعله يعمل فوراً دون الحاجة لتثبيت أي حزم معقدة.

### الطريقة الأولى: الفتح المباشر
- يمكنك ببساطة فتح ملف `index.html` مرتين بالفأرة في أي متصفح (Chrome, Edge, Firefox).

### الطريقة الثانية: تشغيل خادم محلي خفيف (موصى به لمعاينة الفيديو والخطوط)

إذا كان لديك **Python** مثبت:
```bash
python -m http.server 3000
```
ثم افتح المتصفح على: `http://localhost:3000`

أو باستخدام **Node.js**:
```bash
npx serve .
```

أو عبر إضافة **Live Server** في VS Code / Antigravity IDE.

## 🚀 كيفية نشر الموقع مجاناً على الإنترنت (Hosting)

يمكنك رفع الموقع مجاناً بنسبة 100% وبسرعة فائقة عبر أي من المنصات التالية:

### 1. عبر Vercel (الأسهل والأسرع)
1. افتح [vercel.com](https://vercel.com) وسجل دخولك بحساب GitHub.
2. اسحب مجلد `ahmed-hamada-portfolio` وأفلته في Vercel Dashboard (Drag & Drop) أو ارفعه عبر GitHub repository.
3. خلال 15 ثانية سيكون موقعك متاحاً برابط سريع مجاني مثل: `ahmed-hamada.vercel.app` مع شهادة SSL مجانية.

### 2. عبر Netlify
1. ادخل على [netlify.com](https://www.netlify.com).
2. اسحب مجلد المشروع إلى منطقة "Deploy your site".
3. ستحصل على رابط فوري مجاني.

### 3. عبر GitHub Pages
1. أنشئ مستودعاً جديداً (New Repository) على GitHub باسم `portfolio` أو `ahmed-hamada`.
2. ارفع ملفات المشروع.
3. ادخل على **Settings** > **Pages** واجعل الـ Source هو فرع `main` ثم اضغط **Save**.
4. سيظهر موقعك مجاناً على الرابط `https://yourusername.github.io/portfolio`.
